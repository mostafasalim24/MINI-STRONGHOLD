MEDIEVAL UPDATE

- New games start with 8 peasants.
- Base population capacity is 8; each completed house adds 8 to the population limit.
- The final campaign mission starts with exactly 8 extra enemy soldiers (distributed across its three enemy lords).
- Added an original medieval-inspired lute-and-flute music track for peaceful gameplay.
- Increased the density and variety of grass-blade details on grassy terrain.
- The area outside the playable map now renders black.

INSTALL / RUN
1. Extract the ZIP.
2. Open the Stronghold folder.
3. Run RUN_GAME_ENGLISH.bat.

BUILD NOTE
The source and assets were updated and checked for balanced delimiters. A Windows build and gameplay test could not be run in this environment. The BAT file expects MSYS2 UCRT64 GCC and Raylib at C:\msys64\ucrt64.
