MINI STRONGHOLD - ENHANCED ASSET BUILD
=====================================

WHAT'S NEW
----------
- Horse Archer now uses the supplied four-frame mounted archer sprites while moving.
- Two new enemy lords are available in Custom Game:
  * The Arabic Lord: animated walking and attack frames.
  * The English Lord: animated walking and attack frames.
- The two new lords are also animated in mission briefings.
- The original Sultan, Wolf and Wazir remain available.

HOW TO START
------------
1. Extract this whole ZIP to a normal folder (do not run it from inside the ZIP).
2. Make sure MSYS2 UCRT64 and Raylib are installed at C:\msys64\ucrt64.
3. Double-click RUN_GAME_ENGLISH.bat.
4. The launcher compiles StrongholdGame.exe and starts it automatically.

REQUIREMENTS
------------
- Windows 10/11, 64-bit
- MSYS2 UCRT64 GCC
- Raylib headers and libraries in C:\msys64\ucrt64

If compilation fails, open build.log in this folder and check that Raylib is installed.
The executable is built on the first launch; it is not precompiled in this package.

CONTROLS
--------
Use the in-game Help screen for controls. F11 toggles fullscreen.

ASSETS
------
New sprite frames are stored in assets/units/.
The source game and original game assets are preserved.
